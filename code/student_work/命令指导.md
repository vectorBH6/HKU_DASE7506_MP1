

> 每个新 shell 都先激活 venv，并加入项目路径。

```bash
cd /home/rvector/MP1_student_starter/code
source .venv/bin/activate
export PYTHONPATH=/home/rvector/MP1_student_starter/code/student_work:/home/rvector/MP1_student_starter/code
```

激活后命令简化为 `python train02.py ...`、`python evaluate.py ...`。


```bash
python train02.py \
  --implementation student_final \
  --config configs/student_final.json \
  --device cuda --precision bf16 \
  --threads 4 --seed 17 \
  --steps 18000 --batch-size 32 \
  --eval-every 400 --lr 0.003 --warmup 2400 \
  --ema-decay 0.999 \
  --run-dir runs/student_final
```


```bash
python evaluate.py \
  --checkpoint runs/student_final/checkpoint_best.pt \
  --split test
```
