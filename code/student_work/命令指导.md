# 命令指导（MP1 作业）

> 所有操作均在 `student_work/` 目录下进行。`student_my` 是最终提交版本，其余为消融/测试用。
> 以下 bash 示例先 `source` 激活 venv，再 `export PYTHONPATH`，最后用 `python` 直接调用。

---

## 1. 通用前置

> 每个新 shell 都先激活 venv，并加入项目路径。

```bash
cd /home/rvector/MP1_student_starter/code
source .venv/bin/activate
export PYTHONPATH=/home/rvector/MP1_student_starter/code/student_work:/home/rvector/MP1_student_starter/code
```

激活后命令简化为 `python train02.py ...`、`python evaluate.py ...`。

---

## 2. 训练（最终版本 student_my）

```bash
python train02.py \
  --implementation student_my \
  --config configs/student_my.json \
  --device cuda --precision bf16 \
  --threads 4 --seed 17 \
  --steps 24000 --batch-size 32 \
  --eval-every 400 --lr 0.003 --warmup 2400 \
  --ema-decay 0.999 \
  --run-dir runs/student_my
```

---

## 3. 评估（validation）

> 训练过程中已按 `--eval-every=400` 自动评估；如需对指定 checkpoint 重新跑验证集：

```bash
python evaluate.py \
  --checkpoint runs/student_my/checkpoint_best.pt \
  --split val
```

---

## 4. 测试（test）

```bash
python evaluate.py \
  --checkpoint runs/student_my/checkpoint_best.pt \
  --split test
```

---

## 5. 命名约定

| 用途 | 命名 |
|------|------|
| 实现脚本 | `student_work/<run_name>.py` |
| 配置文件 | `configs/<run_name>.json` |
| 运行产物 | `runs/<run_name>/` |
| Best checkpoint | `runs/<run_name>/checkpoint_best.pt` |
| 最终 checkpoint | `runs/<run_name>/checkpoint.pt` |
| 训练指标 | `runs/<run_name>/metrics.json` |

> `run_name` 与 `--implementation` 保持一致，便于回溯实验。
